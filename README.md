# Library Management System

This is a Java-based console application designed as a capstone project to manage a library's collection of books. The project aims to provide practical skills in object-oriented programming, collections, and console input/output.

## Features
- **Add a New Book:** Input the book title and author to add a new book to the library.
- **View All Books:** List all books along with their current status (borrowed or available).
- **Search by Title:** Find a specific book by entering its title.
- **Borrow a Book:** Borrow a book if it is available (a book cannot be borrowed more than once before being returned).
- **Return a Book:** Return a previously borrowed book.
- **Exit:** Return to the main menu after each operation and exit the application only when selected.

## Technologies Used
- Java (Core Java, Collections, and Scanner for input)
- Console/Terminal based application

## How to Run
1. **Compile the project:**
    ```bash
    javac *.java
    ```
2. **Run the application:**
    ```bash
    java LibraryManagementSystem
    ```
